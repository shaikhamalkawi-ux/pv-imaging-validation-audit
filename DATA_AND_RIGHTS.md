# Data access, attribution, and reuse limits

This repository intentionally contains **NO** raw Sandia EL images or IV traces; **NO** original Sandia `AnonDB.csv` source copy; **NO** Scopus, Web of Science or IEEE licensed database exports; and **NO** publisher full-text PDFs or other teams' unreleased labels.

## Upstream original sources

- **Sandia PV-IV-EL**: DOI [10.11578/3818365](https://doi.org/10.11578/3818365), Sandia National Laboratories / OEDI, public source metadata (source catalog CC BY); exact 254907-byte `AnonDB.csv` SHA-256 `8fe450440d989f9aa469f0fc206c76b13021a93dbb6071ddc3a1967fd083440e`. Download from owner and attribute. Do not silently rewrite 616 acquisition rows to the catalog's 613 headline.
- **Pratt, Mattheus & Klein**: DOI [10.1016/j.sasc.2023.200048](https://doi.org/10.1016/j.sasc.2023.200048), source code/EL benchmark [TheMakiran/BenchmarkELimages](https://github.com/TheMakiran/BenchmarkELimages), precise inspected Git tree commit `768b5e78596b429829b6b7aceb0ce4ac7b07788d`. Public directory filenames are inspected; raw images are NOT republished here.
- **Bommes et al.**: DOI [10.1002/pip.3518](https://doi.org/10.1002/pip.3518), published Table-5 numbers are attributed to the authors. No network weights/checkpoints obtained.

No blanket copyright license is inferred merely from the material being public. The project code, draft manuscript and derived files are supplied for inspection; selection of a reusable open-source code license (MIT recommended) and separate paper/supplement rights remains an **author-controlled approval** before a formal open-license grant or a journal deposit. Third-party data retain the owners' licenses. Do not redistribute upstream content contrary to those licenses.
