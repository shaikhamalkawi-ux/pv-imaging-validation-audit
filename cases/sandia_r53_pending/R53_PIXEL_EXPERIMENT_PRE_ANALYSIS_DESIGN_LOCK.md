# 99pv — R53 proposed source-locked Sandia EL-pixel to electrical-Pmp experiment
**Design frozen before any R53 image-level predictor is trained or scored — 2026-11-08.**

## Status and purpose
`R53_IMAGE_SOURCE_PENDING_NOT_EXECUTED`. This is a proposed prospective held-out test on raw Sandia EL pixel data with the *measured electrical IV power ratio* as the endpoint. It does NOT test defect-segmentation/classification performance, independently verify any published Sandia-model score, or imply observed leakage. R52 metadata-only exploratory controls are frozen and must not be relabelled image tests.

**Primary source:** Sandia PV-IV-EL, DOI `10.11578/3818365`. Exact original official metadata is `AnonDB.csv`, bytes=254,907, SHA-256 `8fe450440d989f9aa469f0fc206c76b13021a93dbb6071ddc3a1967fd083440e`, originally 616 rows, 438 distinct Mod_ID, 613 IVPath; retain all original rows in the archive. Raw linked EL.zip from `https://data.openei.org/files/8378/EL.zip` (Sandia catalog says ~2 GB); optional paired `IV.zip` ~44MB. Metadata only is *not* enough for this new experiment.

## Before-analysis file admission
- Download the complete official EL archive by authorized access, without anonymization changes; compute raw ZIP SHA-256 and entry hashes, list all archive members. Verify ZIP CRC and document source URL/access date.
- Match input EL files by `ELHPath`/`ELLPath` in original 616-row CSV. Distinguish source `Mod_ID`, `IVPath`, EL path, EL acquisition date, and repeated IV paths. No guessed link or inferred parent ID.
- Fixed primary eligible set: rows with **both** high- and low-current EL image paths resolvable in the downloaded ZIP, an IV target `Pmp_(W)` and positive `Nameplate_Pmp_(W)` present, equal high/low EL calendar dates, and signed absolute EL-to-IV date lag **<=7 days**. R51 source metadata says 600 two-link rows and 479/600 within 7 days before the nameplate and actual pixel-existence checks; final N MUST derive from the real archive, no imputation.
- No selection on pixel defect content, predictor error or unseen test labels. Record every omitted row and reason. Report separate sensitivity using *all* otherwise eligible time-lag records with no lag cutoff; do not replace the primary cohort after inspecting outcomes.

## Fixed target and experimental unit
- Label is the same **continuous electrical target** as R52, `Pmp_(W) / Nameplate_Pmp_(W)`; measured IV endpoint, not crack severity, error-free true power under new field conditions, or module fault label.
- Physical independence key: the original CSV `Mod_ID` (source-declared physical module). Do not infer cross-plant/site independence from this ID.
- Each seed 20261108…20261207 (exactly 100) runs a seeded 80/20 **row-wise** holdout and a separate **whole-Mod_ID-grouped** 20%-of-eligible-row holdout. Both partitions must be documented as disjoint rows, and the second must have zero intersecting source module IDs. Report row-wise shared Mod_ID and IVPath and available train/test group counts. Do not cherry-pick seeds.

## Frozen image feature representation and model
No deep network is claimed. Use a small, deterministic, transparent 2-channel EL image feature baseline, to avoid post-hoc optimizer/hyperparameter search: For each high and low EL image, load the original TIFF as numeric grayscale with tifffile, verify finite 2D array. Clip independently at each image's empirical 1st and 99th percentile, rescale to [0,1] using the clipped extrema (constant images handled as zeros). Bilinear resize to exactly 64×64 (Pillow), divide into 8×8 non-overlapping blocks. Extract mean and SD in each block plus four global quantiles (0.10, 0.25, 0.50, 0.75) PER CHANNEL. The 2 channels therefore yield 2×(64+64+4)=**264 numeric features**. No original module ID, filename or measured IV values enter these image features.
Fit `StandardScaler` on training features only; `Ridge(alpha=10.0)`, no test-specific model selection. Label Pmp/nameplate ratio. Report held-out MAE ratio percentage points and Pmp watt MAE, plus RMSE and all source/metric denominators. Report equal-physical-module-weight MAE as a secondary analysis; test metric groups may vary with split type. Keep original row IDs and 100 seeds.

Optional predeclared comparators for explanatory context, all evaluated on exactly the same eligible cohort and split sets: (i) constant nameplate prediction ratio=1.0, and (ii) the non-ID metadata Ridge features/alpha from R52, trained fresh on the R53 eligible cohort. Do not combine image and source metadata features in the primary image baseline. No Pmp test data, IV power/current values, future module observations, or ID-based target lookups in any image model.

## Source-quality/robustness gates
- If >=10% of primary metadata rows lack physically decodable image files, stop and publish a source-support HOLD rather than silently using a new sample. If 20% cohort grouped split cannot be formed, HOLD. If positive measured Pmp/nameplate label cannot be verified, HOLD.
- Repeat the primary source result after removing repeated IVPath rows by prespecified upstream key if there are multiple valid EL acquisitions for the same IVPath; report a full eight-choice sensitivity if the original 3 duplicate pairs remain in the eligible cohort (if not, enumerate 2^d choices for d valid duplicates) instead of discarding data silently.
- Paired values from 100 dependent split seeds are a *descriptive design sensitivity*, not 100 independent experiments or a p-value. Do not infer causal optimism or industry failure prevalence. Source-version/labeling/physical site claim remains tiered.
- Outputs: fixed SHA manifest for original ZIP and every used image, row-level eligibility and source-to-target bridge (CSV), frozen source-ID group/row split ledgers, per-seed model predictions with original row ID and source module ID, 100-seed summary, code/requirements, independent clean rerun QA, ZIP CRC, complete source hashes. When imaging archive is too large to redistribute, keep original archive SHA plus per-member content hashes and the public DOI download location. Public/author package must not rehost image bytes without license review.

## Scientific admission
Only after actual TIFF pixels are read, hash-checked and the fixed model is run can any **image-based electrical-prediction** MAE contrast be reported. It still cannot be described as a PV crack classifier, PV fault segmentation benchmark, confirmation of leakage in Pratt/Bommes/other papers, or new-site transfer. For PV defect-metric shift, separately acquire a defect-labeled EL/IR dataset with verified physical parent mapping and exact study/release correspondence, and evaluate mIoU/F1/AUROC under matched protocols. R47 and all previous frozen project baseline results remain unchanged.
